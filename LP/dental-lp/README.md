# Dental Route — 現場改善の窓口

歯科医院向けの現場改善窓口サイトです。

---

## 1. プロジェクト概要

**Dental Route** は、歯科医院の院長・事務長・運営担当者が「今の状況を気軽に共有できる受け皿」として設計されたサイトです。

- サービスを強く売り込むことは目的としていません
- まず医院側の現状を聞かせていただき、その上で何ができるかを一緒に考えます
- 患者様の個人情報・医療情報は一切取得しません
- 成果を保証する表現は使いません
- 対応できないと判断した場合は、正直にお伝えします

---

## 2. ページ構成

| URL | ページ名 | 内容 |
|---|---|---|
| `/` | トップページ | ファーストビュー・自己紹介・実績概要・フォーム |
| `/areas` | 対応領域 | 8つの対応領域と説明 |
| `/results` | 実績・運用例 | 運用改善の事例（数値付き）と注意書き |
| `/philosophy` | 大切にしていること | 7つの価値観・方針 |
| `/privacy` | プライバシーポリシー | 取得情報・利用目的・管理方針 |

> フォームはトップページ（`#contact` セクション）内にあります。フォーム単独のページはありません。

---

## 3. 主な機能

- **状況共有フォーム**（トップページ内）
- **Gmail 送信**（フォーム送信後に Gmail へ通知）
- **送信完了画面**（同一ページ内でフォームと切り替え表示）
- **Basic 認証**（現在は検証用の限定公開）
- **noindex / nofollow**（検索エンジンへの非表示設定）
- **robots.txt Disallow: /**（クローラー拒否設定）
- **スマホ対応**（レスポンシブデザイン）
- **PC ヘッダーナビ / スマホハンバーガーメニュー**
- **控えめなフェードイン演出**（各ページ・送信完了画面）

## 4. フォーム仕様

### 入力項目

| 項目 | 必須 / 任意 | 備考 |
|---|---|---|
| 医院名 | 必須 | |
| ご担当者様名 | 必須 | |
| メールアドレス | 必須 | 形式チェックあり |
| 電話番号 | 任意 | |
| 気になる項目 | 1つ以上必須 | 複数選択可 |
| その他の内容 | 「その他」選択時のみ表示 | 100文字以内 |

### 気になる項目の選択肢

予約導線 / LINE運用 / 掘り起こし / 採用 / 集計・数値管理 / 業務改善 / ホームページ・LP / SNS運用 / その他

### 重要な注意事項

- **患者様の氏名・症状・治療内容・予約日時などは入力させない設計です**
- フォームの送信内容は **データベースに保存しません**
- Slack・LINE などの外部チャットへの通知は **行いません**
- **Gmail 受信のみ** で運用しています

## 6. 環境変数

Vercel の「Environment Variables」に以下を設定してください。  
**コード内への直書き・外部共有は厳禁です。**

```env
# Gmail 送信用（アプリパスワードを使用）
GMAIL_USER=あなたのGmailアドレス
GMAIL_APP_PASSWORD=Gmailのアプリパスワード（16桁）

# 受信先メールアドレス
CONTACT_TO_EMAIL=受信用のメールアドレス

# Basic 認証（検証用の限定公開設定）
BASIC_AUTH_USER=ログインID
BASIC_AUTH_PASSWORD=パスワード
```

### 注意

- `NEXT_PUBLIC_` プレフィックスは **付けないでください**（クライアント側に漏洩するため）
- Gmail アプリパスワードは Google アカウントの「2段階認証」を有効にした上で発行します
- 環境変数を変更した場合は、Vercel の「Deployments」から **Redeploy を行う必要があります**

## 7. 認証・公開設定

### 現在の状態（検証用・限定公開）

| 設定 | 状態 |
|---|---|
| Basic 認証 | **有効**（環境変数で制御） |
| noindex / nofollow | **有効**（`app/layout.tsx` で設定） |
| robots.txt | **Disallow: /**（全クローラー拒否） |

### 検索公開に切り替える場合（現時点では非対応）

将来的に一般公開・SEO対応する場合は、以下をすべて変更する必要があります。

1. `proxy.ts` で Basic 認証を解除（または環境変数を削除）
2. `app/layout.tsx` の `robots: { index: false }` を `index: true` に変更
3. `app/robots.txt` を `Allow: /` に変更
4. Google Search Console への登録
5. sitemap の追加

> **現時点では上記の変更は行わないでください。**

## 8. 触らない方がよい部分

以下のファイル・設定は、不用意に変更しないようにしてください。  
変更すると **フォーム送信・認証・メール受信が壊れる可能性があります。**

| ファイル / 設定 | 理由 |
|---|---|
| `app/api/contact/route.ts` | フォーム送信・Gmail 送信の処理本体 |
| `proxy.ts` | Basic 認証の処理 |
| `app/layout.tsx` の robots 設定 | noindex / nofollow の制御 |
| `app/robots.txt` | クローラー拒否設定 |
| Vercel 環境変数 | メール送信・認証に必要な機密情報 |
| フォームの患者様情報を入力させない注意文 | 医療個人情報保護の観点 |
| 送信完了画面の挙動 | 送信後のスクロール・表示切り替え処理 |
| `app/privacy/page.tsx` | プライバシーポリシー本文 |

## 9. 開発・起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動（http://localhost:3000）
npm run dev

# 本番ビルド（Vercel では自動実行されるため通常は不要）
npm run build
```

> ローカル開発時は、プロジェクトルートに `.env.local` を作成して環境変数を設定してください。  
> `.env.local` は `.gitignore` に含まれているため、GitHub には公開されません。

```env
# .env.local の例
GMAIL_USER=your@gmail.com
GMAIL_APP_PASSWORD=xxxxxxxxxxxxxxxx
CONTACT_TO_EMAIL=receive@example.com
BASIC_AUTH_USER=admin
BASIC_AUTH_PASSWORD=yourpassword
```

## 10. デプロイ方法

このサイトは **Vercel** でホスティングしています。

### デプロイ手順

1. コードを GitHub へ `push` する
2. Vercel が変更を検知して自動でデプロイします（通常 1〜2 分）
3. 環境変数は Vercel の管理画面「Settings → Environment Variables」で設定します
4. 環境変数を変更した場合は、「Deployments」ページから **Redeploy** を実行します

### デプロイ後の確認

- Basic 認証が有効になっているか
- フォームを実際に送信して Gmail に届くか
- 送信完了画面が正しく表示されるか
