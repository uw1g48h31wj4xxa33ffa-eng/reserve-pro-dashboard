# Practice Assistant V2

## 概要
Practice Assistant V2 は、士業業務支援を想定したWebアプリケーションです。
AIが前工程の情報を元に要項や資料を整理し、人間が確認・修正・承認を行う思想で設計されています。

## 基本フロー
1. **補助金支援**
   - **公募要項整理**: AIが抽出した想定要件を人間が確認・修正。
   - **必要資料整理**: AIが抽出した必要資料リストを基に、準備状況を管理。
   - **スケジュール管理**: タスクと期日を整理し、進捗を管理。
   - **納品・提出準備**: 最終的な要対応事項や納品状況のチェック。
2. **規程設計**
   - 規程要件のヒアリングから自動整理、規程生成。
3. **AI検証**
   - AIが提案・生成した成果物（エビデンス）の人間による確認と承認。

## プロジェクトの性質（限定公開デモ / MVP）
- 現在は限定公開デモ（MVP）版として構成されています。
- 主にモックデータとローカルストレージ（`localStorage`）を中心に動作し、ブラウザ上で完結します。
- 実在する顧客情報や機密情報は一切含まれておりません。
- 本番運用にあたっては、データベース、ユーザー認証、権限管理、監査ログ等の追加実装が必要です。

## 技術スタック
- **Frontend**: Next.js (App Router), React, TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Hooks (useState, useEffect, etc.), localStorage

## 現在の主な機能
- 案件一覧とステータス管理
- 各種専用業務画面（公募要項整理、必要資料整理、スケジュール管理、納品・提出準備）
- AI検証・エビデンス承認フロー
