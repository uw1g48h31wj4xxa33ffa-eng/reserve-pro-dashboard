# Ultimate Reserve Pro 予約管理ダッシュボード (モバイル対応版)

## 概要
クリニック向けのプレミアム予約管理ダッシュボードの、スマートフォン（モバイル）およびタブレット等に最適化したレスポンシブバージョンです。
既存のPC向け高機能ダッシュボードと同じロジックを踏襲しつつ、狭い画面でも快適で流れるような操作性を実現しています。

## モバイル対応のポイント
1. **インテリジェント・ナビゲーション**: 
   - PC環境（横幅768px超）では左側の固定サイドバーを表示。
   - スマホ環境（横幅768px以下）ではサイドバーを隠し、画面下部に固定されるプレミアムな**ボトムナビゲーションバー**に切り替えます。
2. **レスポンシブ・カード型テーブル**:
   - スマホ画面では、横長のテーブル（表）表示を自動的に**カード型リスト**へ変換します。各申請情報がブロックカードとして表示され、スクロールや情報確認が非常に容易になります。
3. **ボトムシート型モーダル**:
   - 予約確定、電話案内、顧客情報管理などのポップアップを、スマホ環境では画面下部からスライドアップする**ボトムシート**へ切り替えます。親指一本で安全に操作可能なプレミアムな体験を提供します。
4. **アカウント選択のヘッダー統合**:
   - モバイル時は、公式LINEアカウント（17アカウント）の切り替えドロップダウンがヘッダー内に自動配置され、いつでもどこからでも瞬時にフィルタリングが可能です。
5. **カレンダービューの自動配置**:
   - PCの2列構成（カレンダー＋休診設定）から、スマホでは縦1列構成へシームレスに並び替わります。

## フォルダ構成
- `index.html`: レスポンシブHTML
- `styles.css`: モバイル特化型メディアクエリを含むスタイルシート
- `app.js`: アカウント同期およびボトムナビゲーション連動ロジックを含むアプリケーションコード
- `gas_integration.gs`: スプレッドシート連携用Google Apps Script（PC版と共通）

## 使い方
1. `index.html` をブラウザ（またはスマホブラウザ）で開きます。
2. スマホ環境では、画面最下部のタブ（申請一覧、カレンダー、顧客・ブロック）をタップして画面を切り替えます。
3. 受信した申請カードをタップすると、画面下部から予約確定ボトムシートがスライドアップします。
4. 時間を選択し、「スクリプトをコピー」をタップしてLINE管理画面で返信します。

## スプレッドシートとの連携方法
`app.js` の7行目付近にある `CONFIG.GAS_URL` に、Google Apps Scriptを「ウェブアプリ」としてデプロイした際のURLを入力してください。
